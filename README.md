# Yandex Practicum Go Database and SQL Sprint 8 Final
Итоговый проект обучения языку **Go**, работе с **SQL базами данных** и выполнению **SQL запросов**.

## Описание

Простое приложение для управления посылками (parcels) с использованием SQL базы данных. Реализованы основные CRUD операции и различные запросы для работы с данными.

## Функционал

- **Add** - добавление новой посылки в БД
- **Get** - получение посылки по номеру
- **GetByClient** - получение всех посылок клиента
- **SetStatus** - обновление статуса посылки
- **SetAddress** - изменение адреса (только для посылок со статусом "Registered")
- **Delete** - удаление посылки (только для посылок со статусом "Registered")

## Технологии

- **Go** - язык программирования
- **SQL** - язык запросов к базе данных
- **database/sql** - стандартная библиотека Go для работы с БД

## Ключевые концепции

- Параметризованные SQL запросы (`sql.Named`) для защиты от SQL injection
- Эффективные запросы без лишних операций
- Обработка ошибок при работе с БД
- ACID операции

## Примечание

Проект демонстрирует лучшие практики работы с SQL:
- Использование параметризованных запросов
- Минимизацию количества запросов к БД
- Правильную обработку транзакций и статусов
